# 漫畫翻譯 GUI 操作指南

更新：2026-10-06。現行入口為 `offline_gui.py`，使用本機 OCR／清字／排版與官方訂閱 CLI 文字翻譯（agy、Claude Code、Codex 三選一）。安裝見 [README](../README.md)，測試範圍見 [驗證紀錄](VALIDATION.md)。

## 開啟與準備

```bash
.venv/bin/python offline_gui.py
```

先在所選 CLI 完成訂閱登入（`agy` 另須關閉 **Use G1 Credits**）。程式不代收帳密或 API key。缺少本機模型或字型時，使用主畫面底部「下載／檢查所需檔案…」；命令列準備方式見 [README](../README.md) 與 [修補模型說明](RESTORATION.md)。不需 API key 或額外本機翻譯伺服器。

主視窗上方「說明 → 使用說明」開啟程式內建的操作摘要（內容在 `src/gui/help_text.py`）；「說明 → 關於」可查看版本、程式簡介、版權與使用範圍。版本號定義在 `src/version.py`，須與 `tools/packaging/version_info.txt` 一致。

主畫面明示雲端文字翻譯：按開始會傳送辨識日文、固定名稱及區域 ID（補漏的大字另附其他辨識結果供推斷原句）；不需每批額外勾選。程式不附加圖片或來源路徑，官方 CLI 本身的帳戶及運行資料依其服務處理。額度、連線或逾時錯誤暫停批次，不自動切換付費 API 或本機模型。

## 翻譯引擎與模型

Windows 會保存各引擎上次成功查到的模型清單，重開與切換引擎時立即載入；首次沒有清單時會自動在背景查詢。查詢失敗仍保留既有選項，「查詢可用模型」可手動更新。清單不會自行更換所選模型。macOS 維持原本清單載入行為。

Windows 若在 PATH 找不到 Claude/Codex CLI，會搜尋使用者原生 CLI／npm 安裝目錄、Codex 桌面程式的 CLI 目錄，以及 VS Code、VS Code Insiders、Cursor、Antigravity 的官方擴充套件執行檔；擴充套件優先選較新版本。無需重裝或修改系統 PATH，仍須通過原有訂閱登入檢查。macOS 維持 PATH 搜尋。

Windows 底部的引擎選單、模型欄位與查詢按鈕使用相同高度。模型欄位與展開清單的文字左緣對齊，留白不會加入模型名稱。點模型欄位內文字右側的空白也能展開模型清單；點模型文字仍可直接編輯。尚無清單時，點空白會開始查詢；處理中維持停用。macOS 保留原本控制項外觀與操作方式。

主畫面底部「翻譯引擎」選 AGY、Claude Code 或 Codex，「模型」可從下拉清單選或直接輸入；「查詢可用模型」向 CLI 取得清單（agy 用 `agy models`、Codex 用 App Server `model/list`；Claude Code 用 SDK 初始化回應，新版會附別名對應的實際版本）。缺少 CLI、版本不支援或回傳空清單時顯示原因，不提供寫死的清單。查詢不送出翻譯內容；清單選項不保證帳號目前有權限或剩餘額度。設定記在 `.comic-translator/settings.json`，修訂視窗與 CLI 使用同一份。處理中不能更換。

Windows 的引擎、模型、思考強度與查詢按鈕排在同一行，模型欄位隨剩餘空間伸縮。Codex／Claude 的強度為 CLI 預設、輕、中、高、極高、最高，僅顯示該模型由 CLI 回報支援的等級；不支援強度時停用強度選單，Fast 僅在模型提供獨立 Fast 時顯示。設定依引擎、模型保存，重開立即載入；舊的模型清單缺少能力資料時，會自動在背景補查一次。Claude 也保留 CLI 回傳的別名能力，例如 `sonnet` 與其完整模型 ID 都能選強度；舊快取只有完整 ID 時會自動補查，不更改已選模型。CLI 未回報能力的手動模型維持 CLI 預設，不送出 Fast 覆寫。macOS 原畫面與預設呼叫方式維持不變。

AGY 的思考強度依 `agy models` 實際回傳的同系列版本建立，例如 Gemini Flash 的輕／中／高分別切換到 `-low`／`-medium`／`-high`；Gemini Pro 只回傳輕、高，就只提供這兩個選項。模型與強度會雙向同步並保存，舊快取也可直接使用，不會憑名稱產生清單中不存在的模型。這台 AGY CLI 沒有獨立的 Fast 參數，畫面會隱藏 Fast；官方[執行模式文件](https://antigravity.google/docs/cli/modes/)也指出舊 `/fast` 已移除。

思考強度控制思考量，Fast 是獨立的加速模式，預設不勾選；只有勾選時才送出加速覆寫。Codex 未勾選時沿用使用者的 CLI 設定，若 config.toml 已啟用 Fast，仍可能使用 Fast；這不代表強制關閉。Claude 不載入使用者設定，未勾選時不送出 fastMode 覆寫。[Codex Fast](https://learn.chatgpt.com/docs/agent-configuration/speed) 消耗更多訂閱額度；[Claude Fast](https://code.claude.com/docs/en/fast-mode) 只支援部分 Opus，使用額外計費的 usage credits，不包含在訂閱額度內。程式不會替你開啟 credits 或更換模型。選擇會套用新批次及修訂器的「翻譯此區」；續跑原批次須沿用原模型、思考強度與 Fast 覆寫。Codex 未覆寫時若更改 CLI 自身的設定，現有批次指紋不會偵測這項變化。

三種引擎都只走訂閱登入：呼叫前檢查登入方式（Claude 須為 `claude.ai`、Codex 須為 ChatGPT、agy 沿用原檢查），不符就不傳送文字；並移除 `ANTHROPIC_API_KEY`、`OPENAI_API_KEY` 等環境變數，在空的暫存資料夾執行，Claude 關閉所有工具、Codex 用唯讀沙盒，出現工具動作的結果拒絕使用。更換引擎或模型後，舊批次不能續跑（指紋包含翻譯器），請建立新批次。找不到 CLI 時：agy 會詢問是否開啟官方安裝頁，其他引擎只顯示提示。

Windows 的 AGY 設定檢查若在初始化時卡住，會終止該次 `/config` 程序並重新查詢；最多 3 次，前兩次各 8 秒，最後一次給足 45 秒，讓啟動較慢但正常的 CLI 也能通過。這只適用於尚未送出漫畫文字的設定查詢。設定內容仍須通過原本的訂閱與 credits 檢查；正式翻譯逾時不會自動重送，錯誤會區分「登入／設定檢查」與「翻譯」。macOS 保留原本單次 45 秒的設定檢查方式。

## 加入、選取與開始

1. 加入圖片、資料夾或拖入來源；資料夾展開成圖片清單，這一步不啟動辨識或翻譯。
2. 可用「全選／全取消」、「移除選取」或「清空清單」整理來源。移除只影響清單，不刪原圖。
3. 清單下方的角色對照使用左側多行欄位，每行 `日文原名=繁中譯名`，例如 `マリオ=瑪利歐`。欄位預設約八行高，可拖曳圖片清單與名稱區之間的分隔線調整高度。右側放格式說明與「儲存對照」；可獨立保存，開始新批次時也會保存，下次開啟自動載入。
4. 按清單下方主按鈕。未勾選時處理所有新加入圖片；勾選時只處理勾選的新圖片與失敗／待確認／已暫停圖片，跳過已完成圖片。主按鈕依內容顯示「開始翻譯」「翻譯勾選」或「重轉勾選」。
5. 沒有新待處理項目且未勾選時，可直接「繼續上次翻譯」，自動找最近未完成批次。處理中主按鈕切換為「停止」：Windows 終止獨立的圖片處理程序與正在執行的翻譯 CLI，未完成頁面不輸出半成品，已完成結果保留，可續跑；正在保存結果時先完成該次原子寫入。macOS 維持原本完成當前頁面後停止的方式。

續跑沿用原批次的角色對照及輸出映射；勾選重轉建立新批次，使用目前對照，另存成果。處理中新增的圖片留在清單，確認後再開始。初始化失敗或批次暫停時，未完成工作會回到清單。

辨識到的原名必須對應指定譯名；OCR 漏掉或讀錯原名時，名稱檢查無法代替辨識修正。固定繁中譯名也用於排版，避免拆開角色全名。

## 進度與輸出

主畫面顯示已處理張數、百分比、目前圖片、處理階段及等待秒數。百分比包含失敗頁，不代表全頁成功或剩餘時間估計；結束時另列完成、待確認及失敗張數。詳細紀錄另開視窗。

「儲存至」預設為來源旁的 `translated/final/`。按「選擇資料夾…」可自選輸出資料夾，設定會記住，下次開啟沿用；按「恢復預設」回到來源旁。新批次及勾選重轉使用目前位置，續跑與修訂沿用原批次位置。處理中無法變更位置。

輸出資料夾下建立 `final/`（只有合成 PNG）及 `work/`（JSON、遮罩、`.reserve` 檔名保留紀錄）。資料夾輸入保留相對子目錄；指定位置且有多個來源根目錄時，各自分組以免混在一起。預設來源不可寫時使用 `.comic-translator/outputs/`；自選位置不可寫時會顯示錯誤，供重新選擇。

翻譯檔名為 `<原檔名>_zh-TW.png`，修訂為 `<原檔名>_zh-TW_revised.png`，碰撞自動加編號。成品與工作檔使用 `final`／`work`，程式不再推測舊中文資料夾的位置。先前管線版本的批次需重新建立；原圖與既有成果保留。批次執行中請勿移除 `.reserve`。

續跑核對來源、有效版本、名稱表快照及輸出 PNG 的雜湊／完整性。模型、CLI 執行檔或管線版本變更時需新批次；來源或輸出改變時另存結果。

## 修訂選取圖片

只選取一張圖片，按「修訂選取圖片」。程式以原圖完整路徑尋找最新報告，包含重轉及另存修訂；失敗但有保存辨識資料的頁面也可修訂。沒有報告時需先翻譯，或用 [CLI 本機分析](RESTORATION.md#模型與-cli) 建立報告。沒有可編輯遮罩或遮罩版本不符的報告需以現行流程重建，不再自動升級舊遮罩。

修訂視窗可檢視原圖、譯圖、紅色清字遮罩及放大區域，更正原文／譯文、直橫排、是否套用，並用筆刷加入或排除清字範圍。筆刷模式的游標是圓圈，大小就是實際處理範圍，可用「筆刷大小」滑桿調整（螢幕半徑 3–60 px，隨放大倍率換算成原圖像素）。字型自動選用系統繁中粗體，缺字時使用 Noto 繁中粗體。

**重新辨識**：不會打日文時，按「辨識原文」下方的「重新辨識」，本機用原圖、只留文字、直排分欄三種方式各讀一次，結果列在旁邊的下拉選單，挑最接近的填入原文，再按「翻譯此區」。花體大字（標題、擬聲字）仍可能全都讀不準，此時可直接在「繁中譯文」輸入中文。

「字級 px」填 0 使用原文字級估計；手動字級優先，先換行／換欄，超出範圍才縮小並顯示實際值。仍無法排版時保留上次成功預覽和草稿，修正前不輸出成品。取消套用或清空譯文可選擇保留原文。

Windows 可選取自動或手動辨識區域，按「刪除選取區域」；預覽會從原圖重新合成，恢復被刪區域的原文，儲存時另存修訂。全部區域都刪除時，可明確另存恢復原圖的修訂。macOS 保留原本只能刪手動區域的行為。

Windows 修訂視窗右上方的區域清單顯示十二行，附垂直捲軸，可拖曳捲軸或在清單上使用滑鼠滾輪查看所有區域。預設修訂視窗高度同步增加，讓下方編輯與儲存按鈕保持可見。

自動辨識區域也能調整字級，例如選取文字框後把 0 改成 20。Windows 修訂時，原本就未貼字且未修改的失敗區域不會阻擋其他區域的預覽與儲存；新修改仍失敗或原本成功的區域變成失敗時，會保留上次預覽並顯示區域 ID 與原因。大範圍偵測若與較小文字框高度重疊且辨識到相同日文，Windows 會停用重複大框，保留正常文字框；明確修改過的區域不自動停用。

修改後停止操作約 450 毫秒開始本機預覽，也可按「更新預覽」。模型載入或修補仍需等待；運算中可繼續編輯，過期結果不覆蓋新草稿。**預覽不寫檔；按「儲存成品」才另存 PNG、遮罩與 JSON。** 關閉未儲存修訂會提醒。沒有完成貼字時只保存報告，不輸出原圖副本冒充譯圖。

### 手動補漏字

- 按「框選漏字」，拖曳框住一段文字並留少許空白，避開框線和插圖。放開後只在本機辨識，新增可編輯區域；Esc 取消，框錯可刪除手動區域再框。
- 選取任何區域（含自動偵測的），在「檢視」模式拖曳藍框角點、邊點或邊線調整尺寸。放開後依新框重建遮罩（偵測器的形狀改為手動範圍），重設筆刷修改，保留文字與方向；不自動重新辨識或翻譯。Esc、重疊或超出限制時保留原框。
- 白底氣泡有淡灰殘字時，可按「加強白底清字」重建遮罩並填白；先核對紅色範圍，用排除筆刷保護細節。不適用網點或有色背景；框線及遮罩外像素保留。
- 確認原文後可自行輸入繁中，或按「翻譯此區（雲端文字）」。這會用所選引擎傳送單區原文（原文未改過時附其他辨識結果）與報告保存的角色對照，不傳圖片、不重翻其他區域；失敗時保留草稿。其餘預覽及儲存操作都在本機。

手動區域一律待目視確認；接觸框選邊緣的筆畫預設保留，避免刪掉連出去的畫線。OCR、藝術字及背景修補都可能出錯。

## 補漏偵測

主偵測器（Comic Text Detector）對對話框外的大字（標題、擬聲字）信心很低。管線因此再用 PP-OCR 偵測器以較寬鬆參數補抓它沒框到的文字：

- 框只保留粗筆畫（依筆畫粗細濾掉對話框／爆炸框外緣、愛心與雜點），網點填色的字先補成實心；框旁完整落在範圍內的細小墨跡（網點、愛心、波浪線）一併清除。
- 單獨一個字的擬聲字會沿字的方向接上相連的字（上限為字寬 6 倍），遇分格線、過大或不同方向的墨跡就停止。
- 補抓回來的區域 OCR 必須有至少 3 個假名／漢字才保留；讀不出來的直接丟棄，不佔位，以免擋住手動框選。
- 補抓區域一律待目視確認；周圍幾乎全白時用白色填平，不用 LaMa 補畫，避免髒灰點。

## 命令列

```bash
.venv/bin/python offline.py translate /path/to/page.png --allow-cloud-text
.venv/bin/python offline.py resume /path/to/batch.json --allow-cloud-text
# 指定引擎與模型（預設使用 GUI 儲存的設定，沒有則 agy）
.venv/bin/python offline.py translate page.png --allow-cloud-text --provider claude --model sonnet
```

翻譯及續跑使用所選訂閱 CLI，必須明確提供 `--allow-cloud-text`。名稱表可用 `--glossary names.txt` 指定，每行 `日文=繁中`；多張圖片或資料夾可直接傳入 `translate`，`--output` 可指定輸出位置。續跑沿用批次對照；`--retry-failed`／`--retry-partial` 可明確重試失敗／部分完成頁面。清字模式與本機分析見 [修補說明](RESTORATION.md)。

## 品質限制

偵測／分組可能漏字，幾何排序不保證分鏡閱讀順序，結構與名稱檢查不代表語意正確。LaMa 是推測背景，須核對遮罩內畫線；遮罩外像素一致只是保真邊界檢查。`success` 不代表沒有漏偵測或誤譯。

譯文使用字元層級 `s2t`，台灣用語仍靠翻譯及審校。CLI 在空白暫存工作目錄執行，拒絕工具事件；這不是公開線上或多租戶部署的安全驗收。
