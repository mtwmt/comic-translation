漫畫翻譯器 使用說明
====================

這個程式可以把日文漫畫圖片翻成繁體中文：自動找出圖上的日文、
擦掉原字，再把中文貼回原位，輸出一張新的圖片。原圖不會被修改。

照著下面「第一次使用」的四個步驟做完，就可以開始翻譯。


使用前要準備
------------

1. Windows 10 或 11（64 位元）的電腦，並連上網路。
2. 下面三種付費訂閱「其中一種」（翻譯是透過你自己的訂閱帳號進行）：
   ・Claude（Pro 或 Max）
   ・ChatGPT（Plus 或 Pro）
   ・Google Antigravity
   沒有訂閱就無法自動翻譯，但仍可辨識日文後自己輸入中文。
3. 約 3 GB 的硬碟空間。


第一次使用
----------

【步驟 1】解壓縮並開啟程式

1. 在下載的 ZIP 檔上按右鍵，選「解壓縮全部」，放到桌面或文件資料夾。
   請不要直接在 ZIP 裡面開啟程式。
2. 打開解壓後的 ComicTranslator 資料夾，雙擊 ComicTranslator.exe。
3. 如果出現藍色的「Windows 已保護您的電腦」視窗，
   按「其他資訊」，再按「仍要執行」。
   （這是因為程式沒有購買數位簽章，不是中毒。）

注意：資料夾裡的 _internal 等內容都是程式需要的，
請不要只把 exe 單獨拿出來，要移動時請移動整個資料夾。


【步驟 2】下載翻譯所需檔案

完整版已內附這些檔案，這個步驟可以直接跳過。


【步驟 3】安裝並登入翻譯引擎（三選一）

程式是透過官方的小工具（稱為 CLI）使用你的訂閱帳號，
所以要先安裝並登入一次。選你有訂閱的那一種來做就好。

先打開 PowerShell：按鍵盤的 Windows 鍵，輸入 powershell，按 Enter。
會出現一個藍色或黑色的文字視窗，下面的指令都是貼在這個視窗裡，
貼上後按 Enter 執行。

◆ 如果你訂閱的是 Claude

  1. 貼上這行並按 Enter，等它安裝完成：
         irm https://claude.ai/install.ps1 | iex
  2. 關掉這個視窗，重新打開一個新的 PowerShell。
  3. 輸入 claude 按 Enter。
  4. 依畫面指示登入，登入方式請選「Claude 帳號（訂閱）」，
     瀏覽器會自動開啟，登入並按同意即可。
  5. 看到可以輸入文字的畫面就代表完成了，把視窗關掉。

◆ 如果你訂閱的是 ChatGPT

  1. 貼上這行並按 Enter，等它安裝完成：
         powershell -ExecutionPolicy ByPass -c "irm https://chatgpt.com/codex/install.ps1 | iex"
  2. 關掉這個視窗，重新打開一個新的 PowerShell。
  3. 輸入 codex 按 Enter。
  4. 選「Sign in with ChatGPT」，瀏覽器會自動開啟，登入並按同意即可。
  5. 看到可以輸入文字的畫面就代表完成了，把視窗關掉。

◆ 如果你訂閱的是 Google Antigravity

  1. 依官方說明安裝 AGY：https://antigravity.google/docs/cli/install/
  2. 打開 PowerShell，輸入 agy 按 Enter，依畫面指示登入。
  3. 在 AGY 的設定中把「Use G1 Credits」關掉，否則程式會拒絕翻譯。

安裝方式若有變動，請以官方說明為準：
  Claude：https://code.claude.com/docs/en/setup
  ChatGPT（Codex）：https://developers.openai.com/codex/cli

登入時請務必選「訂閱帳號登入」，不要選 API key。
本程式只使用訂閱額度，不會另外產生 API 費用。


【步驟 4】在程式裡選擇翻譯引擎

1. 如果漫畫翻譯器在步驟 3 之前就開著，請先關掉再重新開啟。
2. 在視窗最下面的「翻譯引擎」選你剛剛登入的那一種：
   ・Claude 訂閱 → 選「Claude Code」
   ・ChatGPT 訂閱 → 選「Codex（ChatGPT）」
   ・Antigravity → 選「AGY（Antigravity）」
3. 「模型」會自動列出可用的選項，不知道選哪個就用預設的。
   清單是空的時，按右邊的「查詢可用模型」。

到這裡準備工作就完成了，之後每次使用只要從下面的「開始翻譯」做起。


開始翻譯
--------

1. 按左上角「加入圖片」選圖片，或按「加入資料夾」選整個資料夾；
   也可以直接把圖片或資料夾拖進視窗。
   支援 PNG、JPG、WebP。加入後還不會開始翻譯。
2. 按圖片清單下方的「開始翻譯」。
3. 等待完成。下方會顯示目前進度；一頁通常需要數十秒到幾分鐘，
   依電腦速度與翻譯引擎而定。
4. 完成後按右下的「開啟成品」，就會打開放翻譯好圖片的資料夾。

成品的位置與檔名：
  預設放在原圖旁邊的 translated\final 資料夾，
  檔名是「原檔名_zh-TW.png」。
  想放到別的地方，按「儲存至」右邊的「選擇資料夾…」。

想中途停下來：翻譯中「開始翻譯」會變成「停止」，按下即可。
已經翻好的頁面會保留，之後按「繼續上次翻譯」就能接著做。


圖片清單的「狀態」是什麼意思
----------------------------

  等待處理          已加入，還沒翻譯
  已輸出            翻譯完成
  已輸出 · 待確認   已輸出，但有些文字程式沒把握，建議打開檢查
  失敗              這一頁沒有成功
  已暫停 · 可繼續   中途停止，可按「繼續上次翻譯」接續

要重翻某幾頁：在清單上勾選那幾頁，按鈕會變成「重轉勾選」，按下即可。


固定角色的中文譯名（可不做）
----------------------------

如果希望角色名字每次都翻成一樣的，在「角色名稱對照」的格子裡，
每一行寫一組「日文原名=中文譯名」，例如：

    マリオ=瑪利歐
    ルイージ=路易吉

寫好後按右邊的「儲存對照」，下次開始翻譯時就會套用。


翻得不好時怎麼修（可不做）
--------------------------

1. 在清單上只勾選一張圖片，按「修訂選取圖片」。
2. 在新視窗左邊的圖上，或右上方的清單裡，點選要修改的那一段文字。
3. 可以做的事：
   ・直接修改「繁中譯文」裡的中文。
   ・字太大或太小：修改「字級 px」的數字（填 0 是自動）。
   ・日文認錯了：按「重新辨識」挑選比較正確的結果，
     再按「翻譯此區（雲端文字）」。
   ・有字沒被翻到：按「框選漏字」，在圖上拖曳框住那段字，
     再輸入中文或按「翻譯此區（雲端文字）」。
   ・不想翻某一段：選取後按「刪除選取區域」，會恢復成原本的日文。
4. 改完後按「儲存成品」。沒有按儲存就不會寫入檔案。
   修訂後的圖會另存成「原檔名_zh-TW_revised.png」，不會蓋掉原本的成品。


常見問題
--------

Q：按開始翻譯後跳出「找不到 CLI」？
A：代表步驟 3 還沒完成，或選錯翻譯引擎。
   請確認「翻譯引擎」選的是你有安裝並登入的那一種，
   然後把漫畫翻譯器關掉重開再試一次。

Q：出現「安全檢查失敗」或要求訂閱登入？
A：代表登入方式不是訂閱帳號。請打開 PowerShell，
   重新執行 claude、codex 或 agy，改用訂閱帳號登入。
   使用 AGY 的話，另外確認「Use G1 Credits」已經關閉。

Q：翻到一半停住，顯示額度不足、連線失敗或逾時？
A：程式會暫停，不會自己改用其他要付費的方式。
   等額度恢復或網路正常後，按「繼續上次翻譯」即可接續。

Q：換了翻譯引擎或模型後，不能「繼續上次翻譯」？
A：這是正常的。請重新加入圖片，按「開始翻譯」重新翻一次。

Q：有些字沒有被翻到，或翻譯怪怪的？
A：自動辨識和翻譯都可能出錯，尤其是手寫字、特效字和標題大字。
   請用上面「翻得不好時怎麼修」的方式修正。

Q：我的圖片會被上傳嗎？
A：不會。辨識、擦字和貼字都在你的電腦上完成，
   只有辨識出來的日文文字和角色名稱對照會送給翻譯引擎。

Q：想把程式搬到別的地方或換新版？
A：請搬移整個 ComicTranslator 資料夾。
   換新版時，把新版解壓到原本的資料夾，
   並保留裡面的 .comic-translator 和 models 兩個資料夾，
   設定和已下載的檔案就不用重來。

Q：程式出錯想請人幫忙看？
A：勾選下方的「顯示詳細紀錄」可以看到詳細訊息；
   錯誤紀錄檔在程式資料夾的 .comic-translator\logs。
   紀錄裡可能有圖片路徑和辨識出的文字，傳給別人前請先看過。

程式內也有簡短的說明：視窗上方「說明」→「使用說明」。
版本與版權資訊在「說明」→「關於」。
