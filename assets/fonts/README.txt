The .otf is not stored in git: `python offline.py prepare-models` (or the GUI's download button) fetches it
from the URL above and verifies the SHA-256. Keep this directory with the application when packaging it.
System fonts (PingFang and Microsoft JhengHei) are loaded from the operating system and are not included here.
